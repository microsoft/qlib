## 解释边界

- initialization-only 控制随机网络本身对真实特征产生结构化排序的可能性。
- 日期 block bootstrap 避免把高度重叠的分钟 Label 行数误当成独立样本量。
- 本实验仅诊断是否存在可重复的 shuffled-label 异常；不证明正式模型有效，也不改变正式模型基线门失败。
- 未读取四月或以后数据，未写入或晋升任何 checkpoint。
