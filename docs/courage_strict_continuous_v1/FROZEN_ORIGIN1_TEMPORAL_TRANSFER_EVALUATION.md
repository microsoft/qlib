## 分钟级结论

- **5m：无可用方向能力。** 三个月 BAcc 都约 `50%`，Spread 均为负，ACC 基本只是类别比例。
- **15m：接近随机且不稳定。** 三月 AUC `49.634%`、BAcc `49.947%`，已经发生方向退化。
- **30m：仅有微弱排序，方向不可用。** 三个月 BAcc 都低于 `50.5%`，AUC 从 `52.362%` 退化到 `50.049%`。
- **60m：一月尚有弱信号，随后衰减。** AUC `52.852% → 51.621% → 50.377%`，三月 BAcc 已低于 `50%`。
- **120m：一月最好，跨月持续衰减。** BAcc `52.160% → 51.777% → 50.557%`，不满足稳定性要求。
- **240m：当前最稳定的 horizon。** 三个月 BAcc 均高于 `52%`，AUC 为 `54.180%/53.708%/54.635%`，Rank IC 均为正；但三月 ACC 仍比多数类低 `8.607` 个百分点，说明它主要有排序能力而非绝对方向能力。
- **480m：排序最强但绝对收益失败最明显。** 三月 AUC 达 `56.821%`、Rank IC `0.07483`，但 ACC 只有 `48.762%`，比多数类低 `10.873` 个百分点，且三个月 480m 零预测 RMSE skill 均为负。

## 关键证据

1. **绝对收益点预测没有稳定通过无信息基线。** 零预测 RMSE skill 在一月、二月为负，三月虽转正但只有 `+0.148%`；相对 Train 中位数常数的 skill 同样跨月换号。
2. **绝对方向能力没有稳定超越类别基线。** ACC 始终约 `52%–53%`，但二月低于多数类 `0.331` 个百分点，三月低于多数类 `4.732` 个百分点；BAcc 与 MCC 也逐月减弱。
3. **横截面排序信号相对稳定。** Rank IC 三个月均为正（`0.05295/0.04597/0.04670`），Top−Bottom 也均为正且扩大；这说明模型学到的主要是股票之间的相对差异。
4. **长 horizon 强于短 horizon，但仍不足以支持绝对方向产品。** 240/480m 的 AUC 和 Rank IC 通常最高；5/15m 多数时候接近随机，三月 15m AUC 已低于 `50%`。

## 决策建议

- 不运行 Origin-2/3 完整训练：它们只能估计滚动重训效果，不能改变当前 frozen model 已暴露的 estimand 问题。
- 暂不做 DataLoader profile：在没有下一轮训练合同前，吞吐优化没有研究收益。
- **不重复做市场共同收益/个股残差取证。** Courage Strict V2 two-layer 已显式构造 timestamp 级 Market target 与 `raw − market` residual target，分别训练、评测并验证 `raw = market + residual`；V2 multirate 又修复 Market loader 过度循环后重新训练和评测。其终局仍为 `FAIL_MULTIRATE_STABILITY_GATE`：March residual 排序为正，April 全面翻负，最终绝对收益未稳定击败 V1 或零预测。
- 对当前 Origin-1 再做事后去均值，只能描述这个 checkpoint 在一至三月的误差组成，不能回答新的路线问题，也不会推翻 V2 已有的 March→April 证据，因此不列为下一步实验。
- 当前路线应在此停止。若另立新研究合同，必须引入与 V2 不同的新假设，例如预注册的 factor-neutral residual/regime conditioning 或真正新增的信息源；不能再次训练同一 Market+Residual 分解。
