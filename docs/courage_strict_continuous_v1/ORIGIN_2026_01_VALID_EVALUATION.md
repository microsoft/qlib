## 边界

- 收益回归值直接作为方向分数计算 AUC，并非上涨概率。
- ACC 排除真实收益恰好为 0 的样本，且必须与同人口多数类、BAcc 和 MCC 一起解释。
- Rank IC/Spread 仅为诊断，不参与 checkpoint 选择。
- 未读取 April、May、June 或更晚数据；未执行 refit、策略、回测、交易或远端推送。

## 训练执行与 DataLoader 观察

- Train `7,301,712` 行，完整执行 `7,131` steps；Valid `1,034,064` 行。
- 8 GPU、BF16、单卡 batch `128`、全局 batch `1024`；每卡 `8` 个 DataLoader worker，总计 `64` 个。
- 总训练耗时 `1006.16` 秒（约 `16.77` 分钟）；稳定阶段吞吐约 `11.5k` samples/s。
- 训练阶段连续采样多数 GPU SM 利用率约 `73%–85%`，偶有单卡瞬时等待；低显存占用来自较小单卡 batch，不等于 GPU 未工作。
- 本次没有中途改变 worker/cache/prefetch，以免正式实验重启或改变合同。剩余 origins 启动前，应先用固定 250-step 样本预算对当前 `8 workers / prefetch 4 / cache 8` 与候选 loader 配置做 A/B profile。

- step `2250` 后 Train loss 继续下降而 Valid 没有改善，step-250 验证与保存最佳 checkpoint 是必要的。
